# E-Commerce Sales Analysis & Demand Prediction

## 📌 Project Overview

This project analyzes historical e-commerce sales data to understand sales performance, product demand, regional performance, and monthly demand patterns.

Machine learning models are developed to predict product demand and support inventory planning.

The project includes Exploratory Data Analysis (EDA), feature engineering, Linear Regression, Random Forest Regression, model evaluation, and future demand forecasting.

---

## 🎯 Project Objective

The main objectives of this project are:

- Analyze historical e-commerce sales data
- Identify sales trends over time
- Identify top-selling products
- Analyze regional sales performance
- Analyze regional product demand
- Identify monthly demand patterns
- Build machine learning models for demand prediction
- Compare Linear Regression and Random Forest Regression
- Forecast future monthly demand
- Generate business insights for inventory planning

---

## 📊 Dataset

The project uses an e-commerce / Superstore sales dataset containing information related to:

- Orders
- Order Dates
- Products
- Customers
- Sales
- Quantity
- Profit
- Regions
- Categories and other business attributes

The dataset contains **10,194 records and 21 columns** after the initial data loading and cleaning process.
